# nu.vex v0.2.0-alpha.6

This is the first downloadable desktop Alpha release of nu.vex. It packages
the same client shell and restricted instance transport that are verified in
the repository's native compilation and runtime checks.

Downloads are provided for:

- Windows x64: NSIS `.exe` installer and `.msi` installer.
- Linux x64: `.deb` package built on Ubuntu 24.04, requiring compatible
  system libraries including WebKitGTK 4.1. Older distributions are not verified.
- macOS Apple Silicon: `.dmg` disk image.

This Alpha is unsigned. Windows SmartScreen, macOS Gatekeeper, and Linux
package trust prompts may warn before installation. Verify the published
`SHA256SUMS.txt` file and read the release manifest before installing.

The Windows MSI carries numeric application version `0.2.0`; the `-alpha.6`
identity is represented by this release tag and its manifest because MSI
metadata does not accept semver prerelease text.

The desktop client connects to an independently hosted nu.vex instance. It
does not include the server or a managed public service. Follow the
self-hosting instructions in the repository before connecting real accounts.

Known limits for this Alpha:

- AppImage is deferred until its bundled Linux libraries and runtime have a
  separate distribution inventory. Linux users can use the Debian package or
  build from source.
- macOS interactive runtime has not yet received the same hosted acceptance
  coverage as Windows and Linux.
- Code signing, notarization, automatic updates, and persistent OS credential
  storage are not included.
- Voice, video, attachments, plugins, mobile applications, and federation are
  planned work.

The release includes the Apache-2.0 project license. Each installer contains a
readable `notices/` collection with exact locked Rust, frontend, font and
platform notice texts and file hashes. See `docs/legal/native-distribution.md`
for collection scope and package-specific limits.
