# nu.vex v0.2.0-alpha.4

**Pre-release Alpha · ajustes del empaquetado Alpha.** Creado por Pablo / ImPaul17.

[Notas originales en inglés](../en/original/docs/releases/v0.2.0-alpha.4.md) · [Descargas](https://github.com/ImPaul17/nu.vex/releases) · [Estado actual](../release-readiness.md)

El cliente de escritorio se conecta a una instancia nu.vex alojada de forma independiente. No incluye el servidor ni activa un servicio público gestionado. Consulta [autoalojamiento](../self-hosting.md) para usar cuentas reales.

Los objetivos son Windows x64 (instaladores .exe y .msi), Linux x64 (.deb) y macOS Apple Silicon (.dmg). Estas notas históricas también contemplaban AppImage; su disponibilidad debe comprobarse en los archivos de la release concreta. La alpha.6 lo aplaza hasta verificar su distribución.

Los paquetes son **sin firma**. Windows SmartScreen y macOS Gatekeeper pueden mostrar avisos. Verifica SHA256SUMS.txt y el manifiesto de publicación antes de instalar. El MSI usa la versión numérica 0.2.0; el estado Alpha se identifica mediante la etiqueta y el manifiesto.

## Límites

- La verificación interactiva de macOS no tiene la misma cobertura que Windows y Linux.
- No incluye firma, notarización, actualización automática ni almacenamiento permanente de credenciales del sistema.
- Voz, vídeo, archivos reales, bots, apps móviles nativas y federación siguen pendientes.
- Esta publicación histórica no incluye los cambios posteriores de la rama de interfaz.

La distribución incluye Apache-2.0 y los avisos de terceros aplicables. Los inventarios legales de estas primeras notas se completaron en las publicaciones posteriores. Consulta [distribución nativa](../legal/native-distribution.md).
